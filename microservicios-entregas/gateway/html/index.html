Crear pedido de entrega

Completa los datos del paquete para crear un pedido. El formulario envía la solicitud al gateway mediante POST /pedidos y muestra el folio, el medio seleccionado y el motivo.

API: POST /pedidos con los 14 campos del paquete. Los botones de ejemplo cargan los datos y crean un pedido. El folio se genera cuando la solicitud termina correctamente.
