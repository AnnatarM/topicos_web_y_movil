### Pregunta 1
*¿Cuál es la diferencia principal entre una metodología de desarrollo tradicional (como Cascada) y una metodología ágil (como Scrum) frente a los cambios en los requisitos?*

Respuesta:

Cuando se lleva a cabo un cambio en los requisitos se afecta directamente el flujo de trabajo de una metodologia tradicional, ya que estas estan pensadas para seguir un desarrollo lineal sin cambios, sin embargo las metodologias agiles estan mas preparadas para este tipo de cambios, en este ejemplo la metodologia Scrum se trabaja por sprints, lo cual permite hacer cambios en los requisitos ya que se hace una revision y planificacion en base a ellos cada sprint, mientras que en la metodologia de cascada todo se debe planear desde un inicio y un cambio provocaria que el proceso se reiniciara.

### Pregunta 2
*Explica la diferencia entre requerimientos funcionales y no funcionales, dando un ejemplo de cada uno aplicable a una plataforma web.*

Respuesta:

Los requerimientos funcionales son aquellos que son muy palpables a la hora de poner en uso el softwarem y por otro lado los no funcionales son los requerimientos más especificos dentro de como funciona el sistema, que puede que un usuario promedio no note mientras esta usando el software pero que sin embargo suelen ser muy importantes a la hora del funcionamiento del software

Ejemplo: 

Requerimiento Funcional: Una pestaña donde ingresar nombre, apellidos y carrera de los nuevo usuarios

Requerimiento No Funcional: Que el registro de la base de datos se haga en menos de 0.001s

### Pregunta 3
*Describe el modelo Cliente-Servidor y explica brevemente cómo se comunican el frontend y el backend en una aplicación web moderna.*

Respuesta:

El frontend se encarga de recabar la informacion que el cliente enviará al servidor, el backend se encarga de enviar la peticion al servidor, recibir e interpretar una respuesta para que despues de nuevo el frontend la muestre al cliente

### Pregunta 4
*¿En qué escenarios recomendarías utilizar una base de datos relacional (SQL) frente a una no relacional (NoSQL) para el almacenamiento de datos en una aplicación?*

Respuesta:

Las bases de datos relacionales son muy utiles ya que a la hora de vincular cierto registro de una base de datos a otro registro distinto de otra tabla, puedes llegar a tener bastante informacion a partir de solo un atributo de un registro de una tabla de la base de datos, tambien serian muy utiles por ejemplo a la hora de asignar relaciones entre ciertos datos de tablas, por ejemplo en registros escolares o de personas.

Es un estilo de arquitectura de software que pone reglas para que dos sistemas se comunican entre ellos, juega el papel fundamental de ser el puente de comunicacion entre los grandes calculos que debe hacer un servidor en base a las peticiones del cliente que en este caso puede ser una app movil, ya que el movil solo envia peticiones y no hace calculos pesados por si mismo

### Pregunta 6
*Explica la importancia de utilizar Git en un equipo de desarrollo de software y describe brevemente qué es un "merge conflict" (conflicto de fusión).*

Respuesta:

La importancia de utilizar git o un gestor de versiones radica más que nada en la facilidad que se le da al equipo de trabajo para trabajar en conjunto y/o al mismo tiempo en un mismo proyecto sin la necesidad de ellos mismos llevar a cabo la orgnizacion de integrar en el codigo "final" las partes de cada uno

El merge conflict resulta cuando intentas integrar los cambios que realizaste en tu rama local del proyecto hacia una rama distinta ocasinando grandes cambios

Respuesta:

Las pruebas unitarias se dan cuando pruebas un solo modulo del software en busca de fallas, y es crucial a la hora de encontrar el lugar especifico donde se encuentra la falla para poder solucionarlo
